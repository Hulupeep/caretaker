# Synthetic replay fixtures

Every CAN frame and reference value in this directory is **simulated**. No vehicle,
ECU, or CSS Electronics sample capture was used. The two CAN runs have separate
timestamps and speed trajectories: calibration fits scale/offset; holdout only
verifies the fixed DBC. `wrong-vehicle-speed.dbc` selects the simulated RPM field
while calling it vehicle speed, and must remain `UNCONFIRMED`.

`t4-demo.jsonl` was generated by the existing `python3 tools/t4/t4_logger.py demo`.
It contains the project's synthetic `074906021F` example, not a physical T4 log.
The demo script regenerates it and checks semantic equality with the Rust output.
