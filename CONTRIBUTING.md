# Contributing

Bring a real problem, reproducible evidence or an improvement to the caretaker workflow. Separate measured observations from guesses, mark simulated examples, and remove personal identifiers and precise location from public contributions. Do not include another project's code without checking its licence. Never commit credentials, vehicle identifiers, owner details or raw private records. Discuss changes that write to machine controls before proposing them; the initial scope is observation and human-reviewed advice.
