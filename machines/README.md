# Machines and systems

Caretaker begins with a T4, but the goal is to learn from many machines: bicycles, boats, motorbikes, mixers, refrigerators, agricultural equipment and more.

**Bring a machine you know.** You can contribute a documented experiment, a machine profile, a sensor setup, an existing repair project or a link to useful work. A repair that failed or a sensor that gave misleading readings is valuable too.

## Add a machine profile

1. Copy [machine-template.md](machine-template.md) to a new, descriptive path such as `machines/bicycles/example-model.md`.
2. Fill in what you actually know; mark the rest unknown. Remove serial numbers, precise locations, personal details and other private data.
3. Link to relevant experiments or existing tools and include their licences where known. Describe compatibility and what you personally verified.
4. Open a pull request, or open an issue if you would rather describe the machine and need help creating a profile.

A profile is a record of evidence and open questions; inclusion here does not mean that Caretaker supports or can repair the machine.

## Existing projects

We welcome links to tools and repair systems built by others, with credit, an honest account of what they do, and a link to their licence. Do not copy code, manuals or images into this repository unless their licence permits it.
