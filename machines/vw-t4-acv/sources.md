## Connector and protocol

- **Physical connector.** SAE J1962, January 1995, figure 5 shows the socket viewed from the mating end. Section 5 identifies chassis ground (4), signal ground (5), K-line (7) and unswitched battery supply (16). The T4-Wiki includes pictures of the dash location, older 2×2 plugs and T4-specific assignments. [SAE J1962, public copy](https://law.resource.org/pub/us/cfr/ibr/005/sae.j1962.1995.pdf) · [T4 diagnostic connector](https://t4-wiki.de/wiki/Diagnosestecker) · [Ross-Tech 2×2 guide](https://www.register.ross-tech.com/vag-com/2x2.php)
- **VW keyword protocol.** SAE J2818 identifies KW1281 as a serial diagnostic protocol. Florian Schäffer publishes original K-line traces for the 5-baud wake-up, complement and echo rules, measuring block request `0x29` and fault memory read `0x07`. `kw1281test` provides an independent implementation reference. [SAE J2818 scope](https://saemobilus.sae.org/standards/j2818_201905-keyword-protocol-1281) · [T4 self-diagnosis](https://t4-wiki.de/wiki/Eigendiagnose) · [Schäffer's KW1281 captures and formulas](https://www.blafusel.de/obd/obd2_kw1281.html) · [kw1281test](https://github.com/gmenounos/kw1281test)
- **Variant evidence.** `074 906 021 F` is documented as an early ACV part number. The linked used-part listing identifies a unit taken from a 1996 ACV. Schäffer's scanned-vehicle list contains a KW1281 result for a later ACV. These are evidence for the starting configuration. The first capture from the target van establishes the actual part number, protocol and baud rate. [1996 ACV ECU listing](https://www.b-parts.com/auto-parts/electrical-and-electronic/control-unit-vw-transporter-t4-bus-70b-70c-7db-7dk-70j-70k-7dc-7dj-25-tdi-bosch-0281001469470-074906021f-vw-vw-1990-1991-1992-1993-1994-1995-1996-1997-1998-1999-2000-2001-2002-2003-2004-5895710) · [VWBusWiki early TDI ECUs](https://www.vwbuswiki.de/index.php?title=TDI_Motorsteuerger%C3%A4t) · [Schäffer's scan results](https://blafusel.de/obd/obd2_scanned.php?order=interf)
- **Field mapping.** T4-Wiki's early ACV measuring-block table and the Ross-Tech label for ACV before April 1999 document the field positions. Expected type bytes and conversions draw on the published protocol captures, which include a different T4 engine. Caretaker's field map is provisional until the expected type, displayed unit and value are compared on the actual ECU. [T4 measuring blocks](https://www.t4-wiki.de/wiki/Messwertblock) · [Ross-Tech on label files](https://www.ross-tech.com/vag-com/labels.html) · [Early ACV label excerpt, reproduced by a forum user](https://vwts.ru/forum/topic/220914/)
- **Independent scan.** Select `01-Engine`, read fault codes, and open **Measuring Blocks**. VCDS-Lite can use a third-party KKL lead on a supported Windows setup. Some groups depend on registration and controller support. A workshop's VCDS or V.A.G. 1551 is another comparison source. [VCDS-Lite interface test](https://register.ross-tech.com/vcds-lite/manual/options.html) · [Controller selection](https://www.ross-tech.com/vcds-lite/manual/select.html) · [Measuring blocks](https://www.ross-tech.com/vcds-lite/manual/measblocks.html)
- **Host timing.** pySerial exposes BREAK and serial I/O. Linux's FTDI driver exposes `latency_timer`, and the FTDI application note describes reducing USB receive buffering for latency-sensitive applications. [pySerial API](https://pyserial.readthedocs.io/en/latest/pyserial_api.html) · [Linux FTDI driver](https://github.com/torvalds/linux/blob/master/drivers/usb/serial/ftdi_sio.c) · [FTDI throughput and latency application note](https://ftdichip.com/wp-content/uploads/2024/03/AN232B_04_DataThroughput_LatencyandHandshaking.pdf)
